# Superseded v3 Prototype

These documents preserve the abandoned v3 development direction for audit
history. They are not current architecture, data policy, verification evidence
or a roadmap.

The prototype reserved five participant-avatar seats and sketched identity,
intent and private-memory seams. No real participant pilot was authorized or
run. v4 removed those seats, and v4.1 removes the dormant schema seams. Current
authority is listed in `docs/INDEX.md`.
